# Nightjar for Homebrew

Nightjar is a local, observable scheduled-job manager for Apple-silicon Macs.

## Install

```sh
brew install --cask piyushpradhan/nightjar/nightjar
```

Nightjar includes a 14-day trial. Learn more at [nightjar.pro](https://nightjar.pro).

## Upgrade

```sh
brew update
brew upgrade --cask nightjar
```

## Uninstall

```sh
brew uninstall --cask nightjar
```
